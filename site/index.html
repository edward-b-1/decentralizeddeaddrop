How it works

Four steps, and none of them involves us.

  1. Run your own server

    One small program on any Linux machine with a public address. It needs no domain name and no certificate authority.

    $ docker compose up -d --build

  2. Scan a QR code to connect

    The code carries the server's fingerprint, so your phone talks only to the machine that holds that key.

    Server fingerprint
    znpepjc55xy7et44kfchuw5zdhaqtoe5r6hfxzkyddzbxkup2erq

  3. Create channels and invite friends

    A channel is a group chat with one owner. Only the owner lets people in, and the server cannot add anyone.

    Family · member list, version 7
    • Sam owner · signed this list
    • Gran member
    • Alex member

  4. Messages are wiped as soon as they are delivered to each device

    If a phone stays away, the server's copy goes when it reaches the channel's maximum message age.

    delivered to every device  → wiped
maximum age reached        → wiped
