Installing it

  1. Open this page on your phone and download the file

  2. Open the downloaded file

    Android asks whether your browser may install apps. Allow it; you can switch that off again afterwards.

  3. Open the app and add a server

    Servers, Add a server, Scan a QR code.

Check what you downloaded

On a computer, both of these should print the values shown above. The first proves the file arrived intact. The second proves who built it, and stays the same from one version to the next.

$ sha256sum deaddrop-0.1.1.apk
$ apksigner verify --print-certs deaddrop-0.1.1.apk

Updates

The app never contacts this website, so it cannot tell you a new version exists. Come back here now and then. Installing a new version over the old one keeps your servers, keys and messages.

Build it yourself

The source for the app and the server is at github.com/edward-b-1/decentralizeddeaddrop, with build instructions.
