Decentralized Dead Drop: app mockup A

A first pass at the main screens, for you to react to. The switches, choices and tabs inside the phones can be tapped. Nothing here is built yet. Example names and addresses are made up.

Everyday use

What someone sees when they open the app, read and reply.

Servers

Adding a server, checking it is the right one, and running your own.

Choices this mockup makes

  1. One list of channels across all servers (screen 1), instead of choosing a server first and then a channel.
  2. Delivery status under your own messages (screen 2). The server does not report this yet. Adding it means each sender learns when the other members collected a message.
  3. A conversation with one person is a channel with two members and sits in the same list ("Priya" in screen 1).
  4. Your name is set per channel (screen 3), so you can be "Robin" in one and something else in another.
  5. Settings screens have Cancel and OK (screen 4) instead of saving as soon as something is tapped.
  6. No fingerprint screen for links and QR codes (screen 6): the app checks silently and only stops if the check fails.
